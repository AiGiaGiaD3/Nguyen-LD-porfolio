# Võ Trung Nguyên · Training Design Portfolio

Static site for GitHub Pages. Open `index.html` locally or publish this folder.

## Structure
- `index.html` — home
- `work/` — four case studies
- `writing/how-i-use-ai-to-design-training.html` — essay
- `img/` — screenshots

## Publish
1. Create a public repo `Nguyen-Portfolio` and upload everything in this folder to the root.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Site URL: `https://nguyenvod3.github.io/Nguyen-Portfolio/`
